## 2.1.8更新内容
- **修复：无块 ID 日常事务按钮状态与记录**
  - 无块 ID 的日常按钮可按自身身份恢复选中状态，点击后正常显示高亮边框；同步、历史记录和统计会继续保存按钮名称、颜色及按钮身份
  - 日常按钮切换时不会用新按钮覆盖旧计时记录，连续点击也会按顺序完成切换
- **优化：日常按钮切换响应**
  - 点击后立即更新按钮状态，旧计时收尾、任务关联和新计时启动改为异步串行处理，失败时自动清理临时状态

## 2.1.7更新内容
- **优化：番茄钟菜单排布与时长选择**
  - 番茄、休息和专注正计时分区更清晰；新增 5～180 分钟时长滑块，可点击开始、拖动调整当前番茄或休息后的下一轮专注时长，并保留常用时长快捷按钮
  - 各阶段菜单会按状态准确显示“完成番茄”“结束休息”“完成专注正计时”等操作，底栏与桌面悬浮窗命名保持一致
- **重构：计时状态与阶段切换逻辑**
  - 计时状态升级为兼容旧数据的 v2 模型，分离专注 / 休息阶段与倒计时 / 正计时模式，并正确保留休息前进度、任务关联和聚焦来源
  - 启动、暂停、停止、重置、完成及模式切换统一通过可恢复事务执行，避免异常中断后出现半完成状态、重复历史或遗漏任务结算
- **优化：多端同步与存储可靠性**
  - 同步会同时校验状态版本与实际内容，并增加设备写入租约、旧读重试和失败回滚；设置、同步及历史文件改为串行写入，降低多端覆盖和写入失败风险
- **优化：历史记录与任务计时结算**
  - 历史记录改用毫秒精度并区分专注 / 休息阶段；不足一分钟的片段仍用于准确结算但可按设置隐藏，Kernel 统计兼容新旧格式
  - 任务时长和实际番茄数通过可去重、可重试的账本结算，保留用户手动修改及任务管理器策略；分钟格式的任务时长属性默认启用，也可继续手动关闭

## 2.1.6更新内容
- **新增：过期事项显示发生时间并支持直接完成**
  - 过期通知会逐条显示提醒的具体日期和时间，可直接完成对应事项；完成后仅移除当前项，跟随任务的提醒会同步任务完成状态
- **新增：升级为内核插件并共享专注数据**
  - 新增 Kernel 专注统计接口，任务管理器可按时间范围读取专注、休息、会话及任务关联数据；统计异常时会安全回退，不再重复扫描或丢失错误信息
  - 多年历史改为按年度分片读取和写入，并限制缓存、扫描量与结果规模；跨窗口写入采用不可变分片和索引提交，降低 CPU、内存占用及并发覆盖风险
  - 最低思源版本调整为 3.8.0，并禁止插件在发布服务中加载
- **修复：同一天事项分组只显示其中一条**
  - 修复提醒查询与 Dock 渲染的过度去重；多条事项即使共用属性宿主或发生时间相同，也会分别显示在过期、明天、本周等分组中

## 2.1.5更新内容
- **修复：计时状态在“未计时”与当前计时之间反复切换**
  - 多端同步改为按单调递增的修改时间、状态序号和设备标识确定唯一最新状态；不同设备序号不一致或版本完全相同时，也不会再让旧的未计时快照与当前运行 / 暂停状态相互覆盖，并会用最新状态修正云端旧快照
  - 同步状态的保存、读取和回调改用独立副本，本机状态更新会持续推进版本；本机回调不再误恢复刚停止的旧计时，其他设备的新状态仍可正常恢复
- **修复：任务属性与提醒可能写入错误块**
  - 任务列表项的番茄时长、实际 / 预计番茄数及任务提醒统一读写到任务项自身，不再因单任务列表、不同入口或任务管理器联动而落到父列表或误将普通块识别为任务；普通块提醒仍保存在原块
  - 已写在父列表的旧计时与提醒属性会在首次读取时迁移到第一条任务项，并同步书签与本机通知预约索引；确认新值写入成功后才清理旧值，遇到冲突会保留双方数据
  - 任务计时结算和提醒增删按同一任务串行写入且只更新目标属性，避免并发覆盖；提醒列表会兼容迁移旧记录并去重，任务截止日、循环规则和完成状态统一从正确任务项读取

## 2.1.4更新内容
- **修复：移动端底部效果遮挡编辑工具条**
  - 关闭“启用移动端支持”后，移动端不再创建或显示底边计时进度条、进度指示器和时间轴；同步恢复、计时刷新或设置刷新也不会重新显示
  - 启用移动端支持时会默认检测软键盘；输入法弹出后自动隐藏进度条与时间轴，点击编辑工具条导致焦点切换时仍保持隐藏，输入法收起后按原设置恢复

## 2.1.3更新内容
- **修复：多端计时状态同步异常**
  - 运行、暂停和停止状态不再因短时间连续更新或重复版本判断被遗漏；同步后若本地计时循环缺失会自动恢复，避免计时完全停止且只能通过重载插件恢复
  - 日常事务按钮的身份和颜色会随计时状态同步，另一端可恢复当前按钮的蓝色选中边框；暂停、继续、切换按钮或停止后，选中状态也会正确更新
  - 兼容旧版同步数据，可按绑定块恢复对应日常按钮，并避免普通任务与日常事务同名时误选按钮

## 2.1.2更新内容
- **优化：正计时达到上限后静默结束**
  - 正计时最大时长由 16 小时调整为 24 小时；达到上限后会自动停止并保存完整记录，不再播放提示音、显示结束弹窗或发送系统通知
- **优化：霓虹发光、呼吸与时间轴动画性能**
  - 连续动画限制为最高 30 帧，并改用合成层位移、缓存视觉样式和复用时间轴片段，减少重复样式计算、DOM 重建与页面重绘
  - 合并重复的呼吸和流光状态更新，页面进入后台或时间轴隐藏时暂停相关动画，在保留现有效果与设置的同时降低资源占用
- **优化：提醒刷新与插件资源占用**
  - 提醒角标、过期检查、任务属性变更和同步刷新会复用同一份数据；本地任务变更即时刷新提醒 Dock，数据库仅在需要读取最新结果时刷新，减少重复查询、云同步和延迟刷新
  - Dock 角标与唤醒恢复调度合并去重，减少延迟刷新和定时器堆积
  - DOM 等待改为按变化响应；插件卸载时会完整清理提醒监听、观察器、定时器、动画样式及图标缓存，避免重载后继续占用资源
- **新增：默认番茄时长联动接口**
  - 其他插件可读取当前默认番茄时长，并在插件加载或设置保存后接收时长变更，提升不同加载顺序下的联动一致性

## 2.1.1更新内容
- **修复：计时结束与暂停边界处理**
  - 计时到期（包括暂停期间到期）会可靠完成停止、记录和结束提示；界面更新、完成动画、弹窗或清理步骤异常时也会继续收尾，避免计时结束后仍停留在运行状态
  - 本地计时心跳异常会记录并在后续心跳重试；最后不足 1 秒按 1 秒计算，避免在最后一秒暂停后停在 0 秒
- **修复：插件重载后专注聚焦丢失**
  - 运行中或暂停中的番茄 / 正计时会保留关联任务块、数据库行及聚焦来源，插件重载后恢复原有专注高亮；空闲或休息阶段不会误恢复

## 2.1.0更新内容
- **优化：轻语数据记录更新适配**

  - 记录会保留轻语返回的记录 ID，并自动写入当前日常事务或计时模式标签；标签会清理不可见字符并规范空格，计时状态中不再重复显示日常事务名称
- **优化：任务提醒草稿联动**
  - 任务提醒联动接口支持在任务创建前打开提醒草稿，待任务创建后再绑定并保存；保存时会校验已有提醒、提醒内容及跟随任务的截止日期，减少覆盖或关联不一致
- **修复：重载插件后任务提醒侧栏会自动展开**

## 2.0.9更新内容

  - 统一番茄、正计时及休息计时在启动、暂停、停止、重置、模式切换、跨端同步、休眠恢复和到期时的收尾逻辑，确保当前片段正确记录；正计时达到 16 小时上限时也会正常完成并提示
- **优化：计时启动与跨端同步稳定性**
  - 历史记录初始化或年度目录创建失败时不再阻塞计时启动；计时启动失败会完整回滚临时状态，避免留下半启动状态
  - 跨设备同步按计时版本和更新时间判断新旧状态，支持另一设备更新状态的恢复，减少旧状态覆盖新状态
- **优化：番茄钟历史记录永久保存**
  - 移除仅保留一年的限制，历史记录按年份写入插件数据目录；升级时安全迁移旧文件和本地后备数据，校验成功后清理旧数据，并支持并发写入与迁移失败恢复

## 2.0.7更新内容
- **新增：任务提醒适配任务管理器 ICS 订阅**
  - 任务提醒联动接口支持按时间范围向任务管理器提供提醒日程，独立循环、跟随任务及 FSRS 间隔重复均可同步到 ICS；已完成任务会自动排除，提醒新增、修改或删除后会及时更新订阅
- **优化：每周循环与跟随任务提醒**
  - 每周循环可选择多个星期，并正确计算间隔周、结束次数、下一次提醒及列表文案；跟随任务时会保留任务设置的星期，FSRS 提醒仅展示当前到期日并等待任务生成下一次复习时间
  - 跟随提醒的编辑和删除改为按字段归属安全联动，避免覆盖任务管理器维护的循环规则或误清除非本提醒写入的任务字段
- **优化：移动端系统通知预约**
  - 任务提醒和计时结束通知增加本机预约记录、状态修复及并发去重；相同预约不再重复取消或创建，完成提醒会清理对应通知，并减少通知元数据引发的重复同步、微信提醒或 ICS 刷新
- **优化：提醒列表中的“更晚”分组默认展开**
- **修复：过期提醒弹出消息支持点击任意位置立即关闭，同时保留 5 秒自动关闭**

## 2.0.6更新内容
- **新增：微信提醒**
  - “提醒设置”中新增“微信提醒”开关；开启后会将未来 7 天内的任务提醒同步到思源云端，并通过微信按时提醒。新增、修改、完成、删除或同步任务后，会自动更新或取消对应的微信提醒
  - 仅支持中国大陆云端区域，且需要有效的思源订阅；开启前会明确提示任务标题和提醒时间将以明文发送到思源云端
- **优化：提醒循环与任务跟随**
  - 编辑提醒时可在“独立提醒循环”和“跟随任务（循环）”之间选择。跟随模式会使用任务的截止日和循环规则，可设置按到期或完成触发；在提醒中修改截止日和循环规则也会同步回任务，提醒时间和备注则只用于通知
  - 独立循环支持永不结束、按日期结束或按次数结束；删除循环提醒时可选择仅删除当前一次并保留后续循环，或删除全部。跟随模式下删除全部还会同步清空任务的截止日和循环规则
  - 提醒列表会分别显示循环和跟随标识，并展示下一次提醒时间；跟随任务可预览下一轮循环时间，设置循环次数时还会显示完成进度
- **优化：任务提醒界面**
  - 调整列表排布、字体颜色和边距；未完成提醒按已过期、今天、明天、本周、更晚及未来年份分组，已完成提醒按今天、近 7 天和 7 天前分组，分组均可折叠
- **修复：Dock 提醒角标不自动刷新**
- **修复：桌面端最小化思源期间计时结束后不弹出完成窗口、也不写入计时记录**

## 2.0.5更新内容
- **新增：今日任务醒目提示**
  - 任务提醒侧边栏的“未完成”列表中，今天到期的任务会以当前主题色描边突出显示，便于在近期提醒中快速识别当天需要处理的任务
- **优化：任务提醒改为延迟合并同步**
  - 新建、编辑、完成、恢复或删除任务提醒后会先完成本地写入和界面刷新，停止操作约一分钟后再合并触发一次思源同步，避免连续修改时频繁同步、阻塞侧边栏操作
  - 侧边栏刷新仅更新本地提醒数据，不再主动触发思源云同步；刷新期间会保留上一份列表，减少加载中的空白和闪动
- **优化：跟随任务提醒联动**
  - 跟随任务的单次提醒会按任务当前的开始 / 截止日期安排；任务完成时可同步标记对应提醒完成，恢复该提醒时也会在确认来源一致后恢复任务未完成状态
  - 兼容已有“提醒完成后同步任务完成”数据，并记录本次提醒对任务完成状态的联动来源，避免误恢复其他完成记录
- **优化：移动端系统通知预约**
  - 保存提醒设置、思源同步完成或任务属性变化后，会重新核对移动端未来提醒预约；关闭系统通知或提醒功能时会主动取消已预约的通知，减少旧提醒仍到点弹出的情况
  - 预约内容变化会被识别并更新，任务标题、备注或时间修改后通知内容可保持一致
- **修复：提醒检查漏检与重复通知**
  - 提醒检查改为覆盖最近一段时间窗口，应用切后台、休眠或检查延迟后恢复时可补发近期错过的提醒，并按日期和时间去重

## 使用指南

本指南面向第一次使用的用户，帮助你快速了解插件的主要功能与推荐操作流程。

### 这是什么

“底栏番茄钟”会在思源笔记底部状态栏增加一个计时控件，支持：

- 番茄倒计时 / 正计时 / 休息计时
- 右键快捷菜单（切换时长、记录分心、查看历史等）
- 任务提醒（侧边栏 Dock 面板：支持块菜单新建、按天/周/月/年循环、今天筛选）
- 历史记录与统计（按日/周/月汇总、目标专注时长）
- 数据导出（ICS：将日常记录导出到日历/分析软件）
- 底部时间轴（可查看当天/前两天的专注区间；跨天计时会按日期拆分显示）
- 日常事务按钮（预设任务按钮，一键开始番茄/正计时，并可用按钮颜色做时间轴高亮）
- 多端状态同步（跨设备延续计时状态）
- 音频提醒、外观主题、任务块联动与番茄时间累加

### 快速开始（最常用流程）

1. 在思源插件管理中启用本插件。
2. 在右下角底栏会看到计时控件：
   - 点击 `▶️` 开始计时，再次点击会暂停/继续（具体取决于当前状态）。
3. 右键底栏计时区域打开菜单：
   - 选择 `🍅` 番茄时长或 `☕` 休息时长即可快速开始对应计时。
   - 计时中可选择 `😵 记录分心`。
   - 选择 `查看历史` 打开统计与记录列表。

### 核心操作说明

#### 1) 开始 / 暂停 / 重置

- 左键 `▶️/⏸️`：开始或暂停计时。
- 右键计时区域：打开快捷菜单（番茄/休息时长、正计时、分心、历史等）。
- 右键长按 0.5 秒：快速“重置当前”（相当于结束当前模式并回到可重新开始的状态）。

#### 2) 计时模式

- **🍅 番茄倒计时**：按预设分钟数倒计时，到期会弹窗提示，并可一键开始休息或继续下一轮。
- **☕ 休息倒计时**：按预设分钟数倒计时，到期会弹窗提示，可一键回到番茄或正计时。
- **⏱️ 正计时**：从 0 开始累计时间。
  - 正计时菜单内也支持进入“休息（正计时-休息）”的衍生模式。

#### 3) 分心记录

计时进行中（番茄/正计时）可在右键菜单选择：

- `😵 记录分心`
- 如果你在主设置开启了“分心记录延长番茄时间（每次+1分钟）”，番茄模式下分心会自动延长当前番茄的剩余时间。
- 主设置支持自定义分心提示文本（支持 `{count}` 占位符），用于分心后弹出的居中提示。

#### 4) 结束弹窗与系统通知

番茄结束/休息结束会弹出弹窗，并触发系统通知（桌面端使用系统通知权限）。

说明：

- 系统通知改为“单次常驻提醒”，点击关闭后才会消失（不再每 60 秒循环提醒）。

#### 5) 任务提醒（Dock）

任务提醒用于给某个任务/块设置“在指定时间提醒我”。

- 启用：在插件设置里开启任务提醒（Dock），然后重载插件生效
- 添加：在块右键菜单或数据库菜单中选择 `⏰ 添加提醒`。添加任务提醒 → 块右上角显示 ⏰ 书签图标，删除任务提醒 → ⏰ 书签图标自动移除
- 循环：支持按天/周/月/年循环（以“日期”输入框为基准；例如每月=每月同一日号、每年=每年同一月日）。
- 管理：打开侧边栏 `任务提醒` 面板，可编辑/删除；支持“今天”筛选仅显示今天会触发的提醒。

### 历史记录与统计（查看历史）

在右键菜单选择 **查看历史** 后，可以看到：

- 今日/本周/本月等统计汇总（番茄次数、专注时长、分心次数等）
- 历史记录列表（可按时间段分组、筛选显示休息记录、隐藏 1 分钟以下记录等）
- 顶部按钮：
  - `⚙️ 设置`：打开插件设置（主设置/同步/音频/外观/任务块）
  - `📅 时间轴设置`：打开时间轴相关设置
  - `📅 导出为 ICS (日历文件)`：导出日常记录为 ICS，可导入 Google Calendar/Outlook/Apple Calendar 等应用进行分析

你也可以在历史界面设置 **每日目标专注时长**，用于统计展示。

### 时间轴（底部全天时间轴）

开启时间轴后，底部会显示“当天时间轴”，并支持查看最近几天：

- 鼠标移入时间轴会自动展开（桌面端）；移出会折叠。
- 可在“时间轴设置”中拖动调整桌面端展开触发区域，区域按可见时间轴的横向百分比保存。
- 点击时间轴上的色块（专注/正计时/休息区间）可弹出详情提示（显示时间段、任务/按钮信息等）。
- 右键时间轴可打开与底栏计时区域相同的快捷菜单。

#### 时间轴刻度与显示

外观设置里提供刻度相关配置：

- 刻度时间位置：上 / 中 / 下
- 刻度仅显示小时（隐藏分钟）
- 刻度字体大小（桌面端/移动端独立设置）
- 刻度线颜色、刻度文字颜色

时间轴设置里提供显示范围、隐藏时间段、刻度间隔、展开/收起高度与透明度等；也可开启“高亮玻璃效果”并调节强度。

### 日常事务按钮（Routine Buttons）

日常事务按钮位于时间轴上方（时间轴展开时可见），用于“一键开始”常用计时任务。

常见用法：

1. 在日常按钮区点击 `+` 添加按钮。
2. 配置按钮：
   - 名称、图标（emoji）、分组
   - 计时类型（番茄计时 / 正计时）
   - 番茄时长（分钟）、可选“休息模式”
   - 按钮颜色与宽度（用于外观与时间轴高亮）
   - 可选填“块ID”用于和任务块联动
3. 点击按钮即可开始计时。

右键按钮可进行编辑/删除/分组排序（移动端支持长按打开编辑菜单）。

#### 按钮颜色与时间轴高亮

时间轴设置中的 `日常事务按钮颜色同步到时间轴`：

- 开启：按钮开始的番茄/正计时会用按钮颜色作为时间轴高亮色（历史与进行中都生效）。
- 关闭：时间轴回退到默认高亮色（番茄/正计时/休息各自的默认色）。

### 任务块联动（📋 任务块）

插件支持把一次计时与任务块/数据库块关联，常见效果：

- 底栏出现 `📋️` 图标，悬停可查看当前关联任务并可清除关联。
- 历史记录与时间轴区间会显示任务信息，点击可跳转到任务块。

#### 任务块番茄时间累加（写回自定义属性）

在设置 → **任务块** 中可启用“任务块番茄时间累加”，把专注时间写回到任务块的自定义属性：

- 小时格式属性（默认 `custom-tomato-time`）
- 分钟格式属性（默认 `custom-tomato-minutes`）

### 多端同步（☁️ 同步）

在设置 → **同步** 中可开启多端同步，让计时状态在不同设备间延续。

常用选项：

- 状态切换时自动触发思源同步
- 同步任务关联（是否同步 task/database 关联字段）

### 音频提醒（🔊 音频）

在设置 → **音频** 中可配置工作结束/休息结束提示音：

- 启用提示音、音量
- 预置提示音（清脆/柔和/警报等）
- 自定义文件（支持上传音频文件）

### 外观（✨ 外观）

在设置 → **外观** 中可配置：

- 主题风格与自定义颜色
- 霓虹发光、呼吸动画、平滑动画
- 进度指示器显示
- 时间轴指示器与刻度外观（颜色、位置、字号等）

### 推荐工作流（示例）

#### A. 经典番茄循环（专注 → 休息 → 下一轮）

1. 右键底栏计时区域 → 选择 `🍅 30分钟` 开始专注。
2. 专注中分心：右键 → `😵 记录分心`（可选 +1 分钟）。
3. 到期弹窗出现：选择 `☕ 5分钟` 开始休息。
4. 休息结束弹窗：选择下一轮 `🍅` 或直接 `⏱️ 正计时`。

#### B. 日常任务一键开始（用颜色区分）

1. 时间轴展开 → `+` 新建日常按钮：如“写作”，设置颜色与时长。
2. 点击“写作”按钮开始计时。
3. 若开启“日常事务按钮颜色同步到时间轴”，时间轴会用该按钮颜色高亮本次区间，回看更直观。

### 常见问题

- **系统通知不弹出**：需要浏览器/桌面端允许通知权限；被系统或浏览器拦截时可能无提示。
- **移动端如何打开菜单**：长按计时区域或时间轴 0.5 秒可打开菜单（不同机型可能有细微差异）。
