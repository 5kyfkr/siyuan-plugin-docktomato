## 2.0.6更新内容
- **新增：微信提醒**
  - “提醒设置”中新增“微信提醒”开关；开启后会将未来 7 天内的任务提醒同步到思源云端，并通过微信按时提醒。新增、修改、完成、删除或同步任务后，会自动更新或取消对应的微信提醒
  - 仅支持中国大陆云端区域，且需要有效的思源订阅；开启前会明确提示任务标题和提醒时间将以明文发送到思源云端
- **优化：提醒循环与任务跟随**
  - 编辑提醒时可在“独立提醒循环”和“跟随任务（循环）”之间选择。跟随模式会使用任务的截止日和循环规则，可设置按到期或完成触发；在提醒中修改截止日和循环规则也会同步回任务，提醒时间和备注则只用于通知
  - 独立循环支持永不结束、按日期结束或按次数结束；删除循环提醒时可选择仅删除当前一次并保留后续循环，或删除全部。跟随模式下删除全部还会同步清空任务的截止日和循环规则
  - 提醒列表会分别显示循环和跟随标识，并展示下一次提醒时间；跟随任务可预览下一轮循环时间，设置循环次数时还会显示完成进度
- **优化：任务提醒界面**
  - 调整列表排布、字体颜色和边距；未完成提醒按已过期、今天、明天、本周、更晚及未来年份分组，已完成提醒按今天、近 7 天和 7 天前分组，分组均可折叠
- **修复：Dock 提醒角标不自动刷新**
- **修复：桌面端最小化思源期间计时结束后不弹出完成窗口、也不写入计时记录**

## 2.0.5更新内容
- **新增：今日任务醒目提示**
  - 任务提醒侧边栏的“未完成”列表中，今天到期的任务会以当前主题色描边突出显示，便于在近期提醒中快速识别当天需要处理的任务
- **优化：任务提醒改为延迟合并同步**
  - 新建、编辑、完成、恢复或删除任务提醒后会先完成本地写入和界面刷新，停止操作约一分钟后再合并触发一次思源同步，避免连续修改时频繁同步、阻塞侧边栏操作
  - 侧边栏刷新仅更新本地提醒数据，不再主动触发思源云同步；刷新期间会保留上一份列表，减少加载中的空白和闪动
- **优化：跟随任务提醒联动**
  - 跟随任务的单次提醒会按任务当前的开始 / 截止日期安排；任务完成时可同步标记对应提醒完成，恢复该提醒时也会在确认来源一致后恢复任务未完成状态
  - 兼容已有“提醒完成后同步任务完成”数据，并记录本次提醒对任务完成状态的联动来源，避免误恢复其他完成记录
- **优化：移动端系统通知预约**
  - 保存提醒设置、思源同步完成或任务属性变化后，会重新核对移动端未来提醒预约；关闭系统通知或提醒功能时会主动取消已预约的通知，减少旧提醒仍到点弹出的情况
  - 预约内容变化会被识别并更新，任务标题、备注或时间修改后通知内容可保持一致
- **修复：提醒检查漏检与重复通知**
  - 提醒检查改为覆盖最近一段时间窗口，应用切后台、休眠或检查延迟后恢复时可补发近期错过的提醒，并按日期和时间去重

## 2.0.4更新内容
- **新增：移动端计时中自动显示悬浮窗开关项**
  - 主设置新增“计时中自动显示移动端悬浮窗”，默认开启；关闭后不会自动弹出，仍可通过移动端文档顶栏番茄按钮手动打开
- **优化：移动端识别与悬浮窗显示边界**
  - 移动端判断优先使用思源官方 isMobile / container / os 与原生桥信号，不再仅因桌面端窗口变窄、触控屏或粗指针环境误判为移动端
  - 桌面端窄窗口不再显示移动端悬浮窗，移动端系统通知预约也会限制在真实移动端场景
- **优化：移动端文档顶栏番茄按钮**
  - 文档顶栏番茄按钮改为跟随思源面包屑栏按钮样式居中显示，修复移动端图标位置偏高、偏移的问题
  - 顶栏番茄按钮继续作为移动端悬浮窗的手动开关，可在自动显示关闭或手动关闭后重新打开悬浮窗
- **优化：关联任务计时的聚焦恢复**
  - 从任务管理器、块菜单或数据库菜单启动关联任务番茄 / 正计时时，会记录聚焦来源；关联任务完成并停止计时后，再从底栏右键菜单继续番茄或正计时，会恢复原任务块 / 数据库行的聚焦高亮
  - 休息结束弹窗中继续下一轮番茄或切回正计时，也会保留关联任务的聚焦状态
- **优化：任务提醒联动**
  - 任务管理器等外部入口创建单次提醒时，可默认跟随任务并保存“提醒完成后同步任务完成”的联动标记；语义识别自动保存提醒时也会读取任务循环上下文

## 使用指南

本指南面向第一次使用的用户，帮助你快速了解插件的主要功能与推荐操作流程。

### 这是什么

“底栏番茄钟”会在思源笔记底部状态栏增加一个计时控件，支持：

- 番茄倒计时 / 正计时 / 休息计时
- 右键快捷菜单（切换时长、记录分心、查看历史等）
- 任务提醒（侧边栏 Dock 面板：支持块菜单新建、按天/周/月/年循环、今天筛选）
- 历史记录与统计（按日/周/月汇总、目标专注时长）
- 数据导出（ICS：将日常记录导出到日历/分析软件）
- 底部时间轴（可查看当天/前两天的专注区间；跨天计时会按日期拆分显示）
- 日常事务按钮（预设任务按钮，一键开始番茄/正计时，并可用按钮颜色做时间轴高亮）
- 多端状态同步（跨设备延续计时状态）
- 音频提醒、外观主题、任务块联动与番茄时间累加

### 快速开始（最常用流程）

1. 在思源插件管理中启用本插件。
2. 在右下角底栏会看到计时控件：
   - 点击 `▶️` 开始计时，再次点击会暂停/继续（具体取决于当前状态）。
3. 右键底栏计时区域打开菜单：
   - 选择 `🍅` 番茄时长或 `☕` 休息时长即可快速开始对应计时。
   - 计时中可选择 `😵 记录分心`。
   - 选择 `查看历史` 打开统计与记录列表。

### 核心操作说明

#### 1) 开始 / 暂停 / 重置

- 左键 `▶️/⏸️`：开始或暂停计时。
- 右键计时区域：打开快捷菜单（番茄/休息时长、正计时、分心、历史等）。
- 右键长按 0.5 秒：快速“重置当前”（相当于结束当前模式并回到可重新开始的状态）。

#### 2) 计时模式

- **🍅 番茄倒计时**：按预设分钟数倒计时，到期会弹窗提示，并可一键开始休息或继续下一轮。
- **☕ 休息倒计时**：按预设分钟数倒计时，到期会弹窗提示，可一键回到番茄或正计时。
- **⏱️ 正计时**：从 0 开始累计时间。
  - 正计时菜单内也支持进入“休息（正计时-休息）”的衍生模式。

#### 3) 分心记录

计时进行中（番茄/正计时）可在右键菜单选择：

- `😵 记录分心`
- 如果你在主设置开启了“分心记录延长番茄时间（每次+1分钟）”，番茄模式下分心会自动延长当前番茄的剩余时间。
- 主设置支持自定义分心提示文本（支持 `{count}` 占位符），用于分心后弹出的居中提示。

#### 4) 结束弹窗与系统通知

番茄结束/休息结束会弹出弹窗，并触发系统通知（桌面端使用系统通知权限）。

说明：

- 系统通知改为“单次常驻提醒”，点击关闭后才会消失（不再每 60 秒循环提醒）。

#### 5) 任务提醒（Dock）

任务提醒用于给某个任务/块设置“在指定时间提醒我”。

- 启用：在插件设置里开启任务提醒（Dock），然后重载插件生效
- 添加：在块右键菜单或数据库菜单中选择 `⏰ 添加提醒`。添加任务提醒 → 块右上角显示 ⏰ 书签图标，删除任务提醒 → ⏰ 书签图标自动移除
- 循环：支持按天/周/月/年循环（以“日期”输入框为基准；例如每月=每月同一日号、每年=每年同一月日）。
- 管理：打开侧边栏 `任务提醒` 面板，可编辑/删除；支持“今天”筛选仅显示今天会触发的提醒。

### 历史记录与统计（查看历史）

在右键菜单选择 **查看历史** 后，可以看到：

- 今日/本周/本月等统计汇总（番茄次数、专注时长、分心次数等）
- 历史记录列表（可按时间段分组、筛选显示休息记录、隐藏 1 分钟以下记录等）
- 顶部按钮：
  - `⚙️ 设置`：打开插件设置（主设置/同步/音频/外观/任务块）
  - `📅 时间轴设置`：打开时间轴相关设置
  - `📅 导出为 ICS (日历文件)`：导出日常记录为 ICS，可导入 Google Calendar/Outlook/Apple Calendar 等应用进行分析

你也可以在历史界面设置 **每日目标专注时长**，用于统计展示。

### 时间轴（底部全天时间轴）

开启时间轴后，底部会显示“当天时间轴”，并支持查看最近几天：

- 鼠标移入时间轴会自动展开（桌面端）；移出会折叠。
- 点击时间轴上的色块（专注/正计时/休息区间）可弹出详情提示（显示时间段、任务/按钮信息等）。
- 右键时间轴可打开与底栏计时区域相同的快捷菜单。

#### 时间轴刻度与显示

外观设置里提供刻度相关配置：

- 刻度时间位置：上 / 中 / 下
- 刻度仅显示小时（隐藏分钟）
- 刻度字体大小（桌面端/移动端独立设置）
- 刻度线颜色、刻度文字颜色

时间轴设置里提供显示范围、隐藏时间段、刻度间隔、展开/收起高度与透明度等；也可开启“高亮玻璃效果”并调节强度。

### 日常事务按钮（Routine Buttons）

日常事务按钮位于时间轴上方（时间轴展开时可见），用于“一键开始”常用计时任务。

常见用法：

1. 在日常按钮区点击 `+` 添加按钮。
2. 配置按钮：
   - 名称、图标（emoji）、分组
   - 计时类型（番茄计时 / 正计时）
   - 番茄时长（分钟）、可选“休息模式”
   - 按钮颜色与宽度（用于外观与时间轴高亮）
   - 可选填“块ID”用于和任务块联动
3. 点击按钮即可开始计时。

右键按钮可进行编辑/删除/分组排序（移动端支持长按打开编辑菜单）。

#### 按钮颜色与时间轴高亮

时间轴设置中的 `日常事务按钮颜色同步到时间轴`：

- 开启：按钮开始的番茄/正计时会用按钮颜色作为时间轴高亮色（历史与进行中都生效）。
- 关闭：时间轴回退到默认高亮色（番茄/正计时/休息各自的默认色）。

### 任务块联动（📋 任务块）

插件支持把一次计时与任务块/数据库块关联，常见效果：

- 底栏出现 `📋️` 图标，悬停可查看当前关联任务并可清除关联。
- 历史记录与时间轴区间会显示任务信息，点击可跳转到任务块。

#### 任务块番茄时间累加（写回自定义属性）

在设置 → **任务块** 中可启用“任务块番茄时间累加”，把专注时间写回到任务块的自定义属性：

- 小时格式属性（默认 `custom-tomato-time`）
- 分钟格式属性（默认 `custom-tomato-minutes`）

### 多端同步（☁️ 同步）

在设置 → **同步** 中可开启多端同步，让计时状态在不同设备间延续。

常用选项：

- 状态切换时自动触发思源同步
- 同步任务关联（是否同步 task/database 关联字段）

### 音频提醒（🔊 音频）

在设置 → **音频** 中可配置工作结束/休息结束提示音：

- 启用提示音、音量
- 预置提示音（清脆/柔和/警报等）
- 自定义文件（支持上传音频文件）

### 外观（✨ 外观）

在设置 → **外观** 中可配置：

- 主题风格与自定义颜色
- 霓虹发光、呼吸动画、平滑动画
- 进度指示器显示
- 时间轴指示器与刻度外观（颜色、位置、字号等）

### 推荐工作流（示例）

#### A. 经典番茄循环（专注 → 休息 → 下一轮）

1. 右键底栏计时区域 → 选择 `🍅 30分钟` 开始专注。
2. 专注中分心：右键 → `😵 记录分心`（可选 +1 分钟）。
3. 到期弹窗出现：选择 `☕ 5分钟` 开始休息。
4. 休息结束弹窗：选择下一轮 `🍅` 或直接 `⏱️ 正计时`。

#### B. 日常任务一键开始（用颜色区分）

1. 时间轴展开 → `+` 新建日常按钮：如“写作”，设置颜色与时长。
2. 点击“写作”按钮开始计时。
3. 若开启“日常事务按钮颜色同步到时间轴”，时间轴会用该按钮颜色高亮本次区间，回看更直观。

### 常见问题

- **系统通知不弹出**：需要浏览器/桌面端允许通知权限；被系统或浏览器拦截时可能无提示。
- **移动端如何打开菜单**：长按计时区域或时间轴 0.5 秒可打开菜单（不同机型可能有细微差异）。
