# Translation maintenance

Dock Tomato ships one plugin with English and Simplified Chinese. Edit the flat
`i18n/en.json` and `i18n/zh-CN.json` files directly. Translation does not require a
build step, a separate plugin, or Task Horizon to be installed.

`index.js` loads the small `i18n/runtime.js` before loading `tomato.js`. The shared
preference is `uiLanguage` in the plugin's existing synchronized
`tomato-main-settings.json`: `system`, `en`, or `zh-CN`. Follow SiYuan uses the host
language on each device; unsupported host languages use English. Changing the
preference saves it first; the user reloads the interface to apply it.

Frontend scripts use `__tt(key, params)`. For HTML attributes, use
`globalThis.__dockTomatoI18n.html(key, params)` to escape text and parameters.
Use `textContent` for plain text. Keep markup in JavaScript. Translation values
are plain data and never run as code. The statistics kernel reads the same files,
with a small formatter for its separate environment and cached language bundles.

Use stable semantic keys, whole messages, and named placeholders such as
`{duration}`. Edit wording without renaming its key. Preserve placeholder names in
both languages. Where the interface explains a literal placeholder, pass it as
data, for example `{ count: '{count}' }`.

Keep IDs, storage keys, record names, custom routine names, attribute names,
repeat rules, and parser keywords independent from presentation. Chinese date
recognition and Lumina journal path tokens retain their existing behavior.
Stored machine dates and time zones do not change with the UI language.

The standalone desktop floating window receives translated labels when its HTML
is built. Its script runs in another window and cannot use the main window's
translator. Encode labels as JSON when passing them into that script.

Run `node scripts/check-i18n.js` and the release verifier. Existing source-slice
tests receive the actual translator through `i18n-vm-fixture`. Older structural
contracts use `i18n-source-fixture` to materialize Chinese strings for their
source assertions. New language tests must use the actual production source.

`README.md` is the English guide. `README_zh_CN.md` preserves the full Chinese
guide and previous release history. Update both when workflows, settings,
installation, or data behavior changes. Keep new release notes in CHANGELOG.md.
